# Evaluation contract

**Goal:** Produce a faithful, ordered transcript of the requested recordings, preserving code-switching or translating it as requested, with uncertainty visible and useful file titles when requested.

**Dimensions:** speech fidelity; language handling; translation fidelity; order and delivery; uncertainty.

**Hard failures:** Inventing speech or concealing uncertain passages; presenting a translation as verbatim speech; reordering messages or omitting a requested recording.
